# Field Mark artwork

These SVGs were supplied directly by the Wildlife product owner on 21 August 2026 for use as
the app's custom collection marks. They are bundled locally and tinted at runtime with the
semantic rarity, Essential and Icon colours.

`rarity_uncommon.svg`, `rarity_rare.svg` and `rarity_very_rare.svg` represent encounter rarity.
`regional_essential.svg` and `regional_icon.svg` represent the two regional standings. Common
encounter rarity intentionally has no mark.

`regional_icon.svg` is the artwork originally supplied as `regional_legend.svg`. The Legend
tier named exactly the same five species per region as the Icon standing, so the tier was
removed and the Icon inherited its mark and its gold.
